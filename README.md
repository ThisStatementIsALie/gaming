# Site of Many a Game

A github page for multiple small games such as Minesweeper and Snake. Only Minesweeper is fully functional at the moment, but more will be added in the future.

Can be found and played at [https://thisstatementisalie.github.io/gaming/MainPage.html](https://thisstatementisalie.github.io/gaming/MainPage.html).

![alt text](https://github.com/ThisStatementIsALie/gaming/blob/main/previewImg.png)

## Features  
The goal of this site is to be similar to neal.fun, where it's a bunch of catalogued games that can be played on the web.  
It includes:  
- Game Selection: Buttons which set which games is selected to play. Refer to GAMES section below for what games are included.  
- ONE Board: A singular board which every game will be on. Every current and future game will use this singular canvas.  
- Game Description: Between the buttons and board is a description which changes depending on the currently active game, featuring the win condition and key-binds.  
- Tracks Wins: When you win a game, the button of that game will turn gold. As games get added, you can challenge yourself to Gold all buttons in one session.

Note that nothing saves (at the moment).

## Instructions
How to play is shown when each game is selected, but here's a brief description of the active games regardless:  

MINESWEEPER: The goal is to dig up every tile on a ten by ten board without hitting any of the 15 mines. To play, you hover your mouse over a tile and click 'z' to dig it, or 'x' to place a flag. If you roll a bad board, you can hit 'r' to reset it. You can reset the board, or press 'dig' if you win or fail.
